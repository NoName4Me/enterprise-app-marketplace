日期：2026-10-13。用户确认采用「清爽工作空间」视觉方向。

## 范围与依据

- 参考 [shadcn Admin](https://github.com/satnaing/shadcn-admin) 的应用目录、导航及卡片层级，使用本项目自己的布局和样式实现，未复制模板源码、引入新依赖。
- 统一侧栏导航、当前页面标识、浅灰背景、白色卡片、紫色强调色、表单与审核状态标签。
- 覆盖登录、应用市场及详情、我的应用及版本历史、应用登记、审核列表及详情、账号管理。
- 账号管理把创建表单和员工列表分为独立区域，保留现有操作与可访问标签。
- 桌面侧栏在窄屏下改为顶部导航，应用列表由三列逐步折为单列；提供键盘焦点与减少动画偏好的支持。
